2-2 · §5.1 SFT

Sample masking: 한 sequence에 묶어도 샘플끼리는 서로 못 본다

Packing은 짧은 샘플 여러 개를 한 sequence에 이어 padding 낭비를 줄이는 것입니다. 그냥 이으면 B가 A를 보게 되므로, 샘플 경계에서 attention을 끊습니다.

packing만

[A1 A2 A3][B1 B2] → B1은 A1–A3도 attend

causal mask = 아래 삼각형 전체

→
packing + sample masking
A1A2A3B1B2
A1✓
A2✓✓
A3✓✓✓
B1✕✕✕✓
B2✕✕✕✓✓

✓ = 볼 수 있음 · ✕ = 막힘 (다른 샘플)

설명용 도식 · A, B = 서로 다른 SFT 샘플의 토큰 · 행 = 현재 토큰, 열 = 참조 토큰

근거: DeepSeek-V3 §5.1 SFT Settings (p.29)Post-training · packing · sample masking
근거 · 2-2

설명용 도식은 원문 문장을 설명하려고 그린 것입니다. 원문은 그림 · 수식 없이 한 문장으로만 적었습니다.

“During training, each single sequence is packed from multiple samples. However, we adopt a sample masking strategy to ensure that these examples remain isolated and mutually invisible.”DeepSeek-V3 §5.1 SFT Settings (p.29)

미기술 position id를 샘플마다 다시 0부터 세는지, 구현(block-diagonal mask · varlen attention 등)은 적지 않았습니다.

출처 전체
  1. DeepSeek-V3 §5.1 SFT Settings (p.29)
설정에서 눈여겨볼 건 packing과 sample masking입니다. 짧은 샘플을 그냥 padding하면 계산이 낭비되니 여러 샘플을 한 줄에 이어 붙입니다. 그런데 그대로 두면 뒤 샘플 B의 토큰이 앞 샘플 A를 attend합니다. 그래서 샘플 경계에서 attention을 끊어, 오른쪽 그림처럼 같은 샘플 안에서만 보게 합니다. 구현 방법은 원문에 없습니다.
